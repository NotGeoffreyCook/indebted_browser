Escrow Park

The amenity courtyard of the Escrow Park Residences. Five segments run clockwise around a central courtyard that stays locked all run and opens as the Target's arena. Each wing is one brand district; the lobby and courtyard sit outside the districts.

Open questions

  1. The macro loop puts combat inside "the store." This layout treats the complex's amenities as that store. Is this a store-type level, or the player's own building? The second would put combat at home.
  2. The courtyard is visible from every wing all run. Should hires and fortifications appear there in real time as a second read on the Target Article, including pay-to-pass upgrades?
  3. G1 has no fee. Should the first gate carry a token fee (~$10) to teach pay-to-pass before it matters?
  4. Electrified pool and falling chandelier are new trap types. They need BudgetCost rows in the shared data table.
