# Changelog

## 2026-11-23
- Store Slice (`index.html`): per-brand display fonts, using the same mapping as the earlier prototypes. GLD = Bebas Neue, RED = Barlow Condensed 900, BLU = DM Mono, GRN = DM Sans 700. Applied to ticker tile names, market/event banners, Tag Bench tag cards, part labels and catalog, punchable machine labels, the RED brand space sign and WALLET game titles. Numbers and prices stay in Space Mono (now tabular figures). Font data lives in `[data-bf]` CSS rules and `BRAND[b].type` / `bfont()` in JS.
