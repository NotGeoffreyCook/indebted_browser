# InDebtEd — Browser Prototype

Top-down browser prototype of **InDebtEd**, a first-person roguelike (UE5) where every bullet costs money and the economy runs on a live stock market across four brands: GLD, RED, BLU, GRN.

This repo is for **mechanics, values and rules**. Visuals, effects and game feel live in the UE5 project, which is also the reference for the part system and repay mini games.

## Run it

Open `index.html` in a browser. It's a single self-contained file with no build step and no dependencies.
